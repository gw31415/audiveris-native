# Original section-to-chunk CLI composition

The actual `stem-chunks-lookup` CLI runs on a 3,035-section original Laura first-system catalog. The request supplies upstream geometry/lookup parameters from the saved original section probe and canonical context from the independent direct original lookupChunks recordings. All 3,048 controls match raw physical glyphs, registered/retained canonical token orders, counts and the full physical registry. This extends the supplied-raw composition to native section lookup and raw factory assembly, including changed null-stump section filtering.

Per-search registries are independent; target/neighborhood selection, item/gap/length maps, cache/head/SIG and epilog remain incomplete. Native request/refusal/resource boundaries are separate tests. No new real scan or special-staff/24-shape full-page coverage is claimed. HEADS/STEMS flags stay false.
