not interchangeable. Original raw output remains at
`/tmp/beam-rest-linked-original/observed.json` in this Cloud.

layered, insertion ordered, Rest-only and cycle safe; an intervening Head does
not propagate it. Actual detector calls Next only for white candidates and
direct Separate for black candidates, then removes black after closure.

a real Rest seed without replacing its previously cached empty beam-list object.
