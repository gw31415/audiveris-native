# Original selected StemBuilder part alignment

1,500 controls execute actual Audiveris 5.11 `StemBuilder.filterUnaligned`
on legitimate CLinker builders initialized by Laura HEADS and original
StemsRetriever.process. Two independent observer compilations and executions
reproduce every original result byte for byte. Candidate glyphs are prescribed
independent rectangles; their collection is not automatically discovered.

Both directions, horizontal/vertical run tables, heights3/7/15, offsets,
empty/reversed/duplicate collections and existing stump entries are compared.
All controls use actual nonnull stumps and observed skew0, dx1.65/dy44.
Native results preserve the caller collection order, distinct caller object
identities and duplicate aliases. 2,810 removed entries match exactly. The
physical barycenter is unrounded. Registry, cache and SIG are unchanged.

Native custom-threshold, fractional-centroid, null-stump, malformed identity,
finite-parameter and resource-budget checks are separate boundary tests;
they are not additional independently observed original controls. Nonzero
skew is explicitly refused. Caller IDs are positive identity tags, not
GlyphIndex content IDs or JVM numeric IDs.

Automatic seed/section collection, full builder filter/item expansion,
head/beam linker conflicts, finalizers and STEMS epilog remain pending.
Laura352 heads/513 exclusions and all prior reports are preserved. HEADS24
whole-page propagation, arbitrary special staff and published scans remain
unverified; HEADS/STEMS completion flags stay false.
