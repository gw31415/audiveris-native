# Fixture provenance

`edge-noise.pgm` is deterministic original synthetic raster data. `original-exercise.pgm` and `.png` are identical original staff-and-seven-note test artwork created by `scripts/make_fixtures.py` on 2026-10-02. No scanned score, publisher engraving, font, or third-party melody is copied. The generator and these three generated files are dedicated to the public domain under CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/); the dedication covers any rights in this new test artwork. CC0 legal text is supplied as `CC0-1.0.txt`.

The exercise contains five staff lines, filled heads, stems, ledgers, a barline and a background gradient. It is a license-cleared original score-like fixture, not evidence of recognition accuracy on professionally engraved or scanned music. Three separately sourced OpenScore/Lieder CC0 MSCX scores and their manifest were copied read-only from the independent audit task and every SHA-256 verified. They are source notation only; rendering and native/Java image comparison remain pending. Upstream `data/examples` was inspected but not promoted to a cleared corpus merely because the repository has a software license.

Regenerate with `python3 scripts/make_fixtures.py`. Hashes and oracle outcomes are in `evidence/java-parity.json`.

`scale/` adds 18 original generated grayscale geometry fixtures under the same CC0 dedication, with dimensions, purpose and SHA-256 in `scale/manifest.json`. `scripts/make_scale_fixtures.py` regenerates them. `scale/peak-goldens.txt` contains numerical outputs of the pinned Java HiLoPeakFinder for 128 fixed synthetic histograms; generated by `scripts/peak_goldens.py`, with the generator covered by AGPL-3.0-or-later. They are regression data, not a scanned-score corpus.

`sections/` contains 8 CC0 original generated stress rasters (curve, slope, noise, two staves, breaks, crossings, straight and blank). `rendered/` contains the CC0 OpenScore An Laura page-1 raster at 180 DPI, 1489x2104, without resizing. PNG alpha was composited on white then converted to grayscale using the documented fixture adapter. The renderer wrote a complete PNG then exited abnormally; output decoding and visual inspection succeeded but process success is not claimed. See `rendered/manifest.json` for provenance, hashes and qualifications.

GRID semantic fixtures generated by scripts/make_semantic_fixtures.py are CC0
synthetic pixels. They are not real user ratings or music recognition events.
Their official phase/final observations and GRID-only staff-mask hashes are
explained in docs/GRID-SEMANTICS.md; original upstream source copies retain AGPL.


## Beam preparation fixtures

`official-grid/beams-*.png` are 12 independent synthetic beam/head/staff renderings made by `scripts/java/MakeBeamsFixtures.java` with the pinned official Bravura font. The font's SIL OFL notice is retained in `crates/audiveris-template-bank/assets/BRAVURA-OFL.txt`. Render inputs, source/hash, raster hashes and original execution provenance are under `evidence/beam-preparation-oracle`. `official-beams/*.json` contains development-only original Audiveris observations; the native runtime does not load them. `beam-structure-source` contains retained official-JAR bytecode observations for unfinished downstream work, not an implemented stage. `beam-spots-controls*` record directly original small-input pixel controls with separate provenance.


## Beam prolog and head sizing

`official-beam-prolog/` contains atomic original `BeamsStep.doProlog` observations; all 13 whole original finals match independently saved plain-step results. Historical v15 `official-beams/` files are unchanged. See `evidence/beam-prolog-oracle` for observer/GC controls, `black-head-{sizer,font}-controls.json` for direct original controls, and `black-head-provenance.json` for pinned JAR/font/source hashes. Generic `assets/black-head-font-metrics.json` stores reusable font widths, never image-recognition outputs. Independent curve containment controls are in `evidence/beam-prolog-review`.
