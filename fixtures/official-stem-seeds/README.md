# Original live STEM_SEEDS oracle

Eleven independent raster executions after complete original live HEADERS and
STEM_SEEDS, before BEAMS/LEDGERS. Java is development-only. Each output includes
stem scale/histogram, exact encoded buffers, GRID section inputs, original
filament/check details and accepted VERTICAL_SEED glyphs.

The final original-step crosscheck, exact pins/hashes, input recipes and limits
are recorded in `evidence/stem-seeds-oracle-validation.json`. Read
`docs/STEM-SEEDS-DEPENDENCIES.md` before implementing masks: in the pinned
runtime, Graphics2D edits to `ByteProcessor.getBufferedImage()` do not change
the source/returned ByteProcessor, and the scaler histogram sees unchanged
NO_STAFF pixels. The separate small buffer control retains exact input/output
bytes.

Accepted seed geometry is canonicalized for comparison; original filament
candidate ordering and acceptance flags remain in `systems[].candidates`.
These glyphs are not final StemInter recognition results.
