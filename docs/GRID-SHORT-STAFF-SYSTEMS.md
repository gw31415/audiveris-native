# Native short-staff system prerequisite

PeakGraph.findAllAlignments obtains the original sorted StaffManager vertical-neighbor chain below each staff. If it is empty, or its first staff has a different short status than the current staff, no alignments are sought. Otherwise it loops top peak, then neighbor staff, then bottom peak in that order. Native system construction now follows this rule using the already implemented original horizontal/vertical staff geometry, and removes its blanket rejection of all short staffs. Short status follows original detectShortStaves: any horizontal neighbor marks the staff short. Existing alignment grades, connection checks, merge-split rejection, purge traversal and system-top construction remain in place.

New actual raster controls use the unmodified original LinesRetriever/StaffProjector/PeakGraph through GridProbe, rather than native-generated expectations. The two-column raster provides four short staffs, six positive bar connections and two initial systems. A mixed full-width/short layout verifies original short-status compatibility rejection. Existing real Laura and raster GRID coverage is retained.
