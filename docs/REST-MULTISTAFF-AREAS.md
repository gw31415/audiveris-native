# Native bounded multi-staff rest association

SystemMapping consumes native GRID curves for one full-width system, up to 32 vertically ordered five-line staves with the same horizontal span, and the complete native vLag/hLag. Staff IDs must match the system's encounter order. Multi-system, unequal-span/column, overlapping staff-band and tablature layouts reject explicitly.

The mapper assembles exact Bezier staff-area paths using the existing native java.awt.Area translation. Following original StaffManager.computeStaffArea/getGlobalLine, the north boundary is the preceding staff's last line plus the rounded sheet vertical margin; the south boundary is the following staff's first line minus that margin. Missing neighbors use sheet edges. Curve endpoint extensions are horizontal, and full sheet x bounds retain java.awt.Area boundary semantics. These staff areas overlap between staves; they are not midline partitions.

getClosestStaff first filters through area containment, compares original Staff.distanceTo = int(max(firstLineY-y,y-lastLineY)) with Java truncation, and retains the first staff on ties. getStaffAtOrAbove returns that staff when its first line is at or above the point, otherwise the preceding system staff, or no staff. CLI beam centers retain integer original bounding-box center semantics. Each selected staff supplies its own native profile and endpoint pitches to the existing rest detector and shared graph conversion pipeline.

MultiStaffAreaControlProbe invokes unmodified original StaffManager.computeStaffArea/getClosestStaff and SystemInfo.getStaffAtOrAbove with supplied curved two-staff geometry. The 252 controls include 131 staff selections and 121 no-staff results, area overlap, exact/outside x/y edges, curved line abscissas, and truncated-distance ties. Native outputs are not used to construct expectations. Supplied controls do not demonstrate positive raster rest conversion. Existing 220 straight-ledger, 21 empty-ledger and eleven complete rest conversion controls remain retained.

Native GRID still emits an empty pre-LEDGERS ledger map. Supplied straight-ledger curve consumption is supported separately; native ledger discovery and curved populated ledger paths remain unfinished. Multiple-system rest dispatch and general horizontal-neighbor/short-staff area chains remain unsupported. The validated e13359df checkpoint's full debug/release result remains 297 tests each; current full suites are unverified and are deferred until coherent. Positive real-score rest conversion and full OMR/MusicXML are not claimed.
