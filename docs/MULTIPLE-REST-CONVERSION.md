# Integrated native multiple-rest conversion boundary

multiple_rest_pipeline::process connects real SystemCandidates to native admission and cached per-staff serif detection, discovers all plans, registers every rest and LEFT/RIGHT serif plus relations with canonical glyphs, then updates real beam tombstones, exclusions and GroupPass memberships/supports/bounds. The native phase identities remain separate from GRID/SIG global identities. Native discovery now avoids staff lookup for short beams before querying endpoint pitches, matching original process order.

Eleven new independent controls execute unmodified original MultipleRestsBuilder.process with actual original five-line staff geometry, supplied synthetic pixels and supplied vLag/hLag sections. A normal original StaffProjector for the actual sheet/staff is cached with the supplied pixel filter. No acceptance method is replaced or bypassed. Its side queries, peak construction, filament/glyph construction, rest/serif vertices and relations, and final SIG beam/group deletion all execute original code. Six positive cases vary serif width 1/2/4 and height 24/36. Five negative cases omit left/right/both serifs, use a below-threshold beam, or violate endpoint pitch. The first probe setup failed because BasicLag.insert had no RunTable; backing tables fixed that initialization and the full failure log is preserved.

The integrated native pass matches six complete rest conversions and five non-conversions, source beam bounds, rest grade/height/median/staff, ordered LEFT/RIGHT relations, serif median/width/grade (within 1e-10), every glyph pixel/bounds, beam tombstones and empty/surviving singleton groups. This is complete conversion equivalence at the supplied staff/lag boundary, not real-score OMR or page-wide extraction. The tests consume the original inputs; no expected result is generated from native outputs. Sixteen focused tests across eight targets, fmt and all-targets Clippy pass. Full release workspace validation is recorded separately below and verified against code/test/fixture hashes; current full debug is not yet run.

Shared SIG/pipeline integration is blocked by an architectural gap: SystemCandidates, GroupPass and RestGraph each use phase-local identities, while GRID serializes its own JSON vertex/relation store and sig_context only accepts GRID classes. A shared vertex-ID allocator, common typed relation store and GRID/beam/rest adapters are needed before these phases can mutate one graph. CLI has no combined BEAMS/rest runner. Staff-at-or-above/pitch mapping and native system-bounded vLag/hLag extraction remain supplied. Multi-beam/multi-staff interactions, sloped geometry, other scales and chunks, conversion error rollback, real-score recognition, epilog and CLI wiring remain unverified/unfinished. Full OMR remains unfinished.
