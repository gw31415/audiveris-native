# Page-state head target planner

`audiveris-native stem-head-plan REQUEST.json REPORT.json` connects automatic beam neighborhood collection, initial lookup-area candidate filtering, group selection and beam endpoint/area selection. The request schema is `audiveris-native.stem-head-plan-request.v1`; each system supplies bounds, vicinity margin, beam IDs, complete beam/group geometry, beam bounds/removal states, and head corner requests with head bounds. Stable sorting by beam rectangle x recreates the original inspect order. Removed beams are skipped; rectangle edge touching has no positive overlap; original ordered-scan termination is retained. Duplicate input beam IDs retain duplicate occurrences. Head initial area uses the existing Java-compatible LinearArea intersection implementation.

The request intentionally requires head corner references, per-head directions/scale tolerances and complete beam/group state. This is a native **page-state planner**, not complete automatic image processing. It does not construct items, choose final glyph prefixes, create/register/cache stems, connect heads in shared SIG, or run cleaner/epilog. Its results retain the initial line, separate area line and target point for those downstream dependencies. IDs are caller-local Inter/group identities per system, not JVM/physical glyph registry IDs.

Direct original5.11 comparison covers both Laura systems and1408 actual head corners, plus14 rectangle edge/overlap/duplicate/removed/empty controls. Two independently compiled original executions match byte-for-byte; the actual native CLI matches every declared case. The original switches the beam list to width order during linking, so the observer explicitly restores preinspect x order. This is distinct from earlier3000 first-system supplied-neighborhood/small-head controls and from native raster end-to-end parity.

The CLI validates all systems before creating its report and refuses existing outputs. Input16MB, output32MB,64systems,8192corners,16384total catalog beams and20M beam/corner work are bounded. Malformed/late inconsistent IDs and nonzero skew refuse without output. HEADS/STEMS remain false. Full page cache/SIG, cleaner/epilog, nonzero skew, real scanned/special staff pages and full24-shape propagation are unfinished/unverified.
