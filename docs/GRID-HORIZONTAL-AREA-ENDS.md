# Native horizontal system-area end prerequisite

SystemManager.horizontalNeighbor scans the existing system encounter order backward for LEFT and forward for RIGHT, selecting the first strict y-overlap. SystemInfo.yOverlaps compares coordinate top/bottom (not Area bounds); touching edges do not overlap. SystemInfo.getRight returns left + width (without subtracting one); native GRID width is max staff right - min staff left + 1. Original computeSystemArea takes integer midpoints of the neighbor right and current left, or current right and neighbor left; absent neighbors use sheet endpoints. The native helper implements these rules directly and native GRID now calls it on coordinates produced from its staff curves. Existing single-column real inputs retain their outputs.
