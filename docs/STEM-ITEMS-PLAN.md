`audiveris-native stem-items-plan REQUEST.json REPORT.json` constructs items from declared prefiltered physical glyph/linker sources, preserves the starting half linker while sorting the suffix, inserts permitted gaps, truncates at the first excessive gap and computes profile length maps. Input schema: `audiveris-native.stem-items-plan-request.v1`; see `scripts/stem_items_plan_request.py` and `fixtures/official-stem-item-events/cli-request.json.gz` for an actual request.

Each case supplies direction, theoretical start ordinate/yRange, selected physical source glyphs, linker references and optional beam height/CLinker head bounds, gap map, stem/max profiles, initial lengths and zero skew. Tokens identify caller items; duplicate tokens require identical sources. Tokens are not glyph registry or SIG IDs. Source glyph pixels determine center lines; half/glyph contributions clip to yRange and full linker contributions retain stump height. Profile4 length selection does not implement artificial stem creation.
