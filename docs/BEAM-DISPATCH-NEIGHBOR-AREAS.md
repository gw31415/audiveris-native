# Beam dispatch through original GRID neighbor areas

The earlier adapter inferred vertical system neighbors from adjacent vector entries. Native GRID already discovers original horizontal/vertical neighbor chains, so horizontally adjacent systems legitimately have different north/south metadata. Dispatch now builds the original global system areas under the explicit audiveris-native.grid-ir.v1 schema from complete native Staff abscissas and validates the supplied horizontal ends, vertical margin, scalar neighbor IDs and any chain arrays against that mapping. Incomplete span metadata and contradictory neighbor metadata return errors; there is no error-triggered geometry fallback. Supplied adjacent-column geometry without a native GRID schema retains its independent clip representation, including original supplied clip controls with Staff spans. Unknown declared schemas return an unsupported error.

SpotsBuilder dispatch first queries SystemManager.getSystemsOf at each integer glyph centroid, then applies the inclusive SystemInfo left/right staff-span filter. The same canonical registered spot may belong to multiple overlapping areas; insertion order and existing groups remain stable. Beam-side containment checks both endpoints against the same original system area. Curved clipped point containment uses the existing exact path/rectangle conjunction; general clipped boolean bounds remain unimplemented. Aggregate point-query and registration budgets remain enforced.

Independent original controls cover nine horizontal/vertical/curved layouts and original Laura geometry, including exact clip and staff-span boundaries, positive/absent selections and both beam ends. An actual two-column raster made from the retained double-beam fixture is processed by original GRID, live HEADERS, STEM_SEEDS, SpotsBuilder.buildSpots and dispatchSheetSpots: fourteen grouped spots, seven per column. Native masks, canonical pixels, ownership and order match. Repeated dispatch preserves identity, and pure spot registration leaves the shared GRID graph unchanged. Existing thirteen beam raster regressions remain checked.
