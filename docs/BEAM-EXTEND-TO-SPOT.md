# Bounded native spot extension

`SpotPool::prepare` reproduces the owning system's BEAM_SPOT free-glyph list, original `(top,left,id)` full-ordinate order, and removal of the builder's assigned spots. `SystemCandidates::extend_to_spot` ports original `BeamsBuilder.extendToSpot` at `9e1e55cd2746037d059345881c53e6a6754bffbd`. It uses the typed owning pool, checks glyph-bounds intersection with the unexpanded side area, stably sorts by left x, removes the current beam's canonical glyph, then selects LEFT last / RIGHT first. It tries only that spot, with no farther-candidate fallback after rejection.

Default reach is Math.rint(0.5 * interline), capped by the original side-gap limit. LEFT extends to the selected spot's left bound; RIGHT uses `left + width - 1`. The point can lie beyond search reach when only part of the glyph bounds intersects the search area; it is not clamped. Original LineUtil.intersectionAtX supplies the point and the previously verified point-extension gate/grade/lifecycle supplies acceptance. Assigned and owning pool identities remain unchanged on success and rejection. No extra system-area containment policy is added beyond original ownership and search bounds.

`side_through_spot` composes the existing merge/side-gap/stem path with real spot processing. Successful earlier merges or stems return immediately. Only NeedSpot reaches this branch. Rejection returns NeedParallelOrNextSide and stops before any parallel call or whole-loop scheduling; no false placeholder substitutes for a downstream branch.

140 independent original controls include 138 real private spot-method invocations, 79 accepted spot replacements, and 2 accepted original stems that skip the spot method. Four scheduling controls invoke original getSideBeam/LEFT merge/stem before spot processing. The matrix covers owning/group/assigned filters, original full-ordinate and stable abscissa ordering, own-glyph removal, both sides, strict area bounds, zero/one/capped search reach, odd-interline ties-to-even rounding, short-gap and blank-foreground rejection, point grade and register/append/remove/exclusion state. Four paired counterfactual controls prove the selected nearest spot can reject even while the same scene's farther spot alone would accept.

The real Book/Sheet/Grid/SIG, registerBeam and InterIndex methods are unmodified. Independent controlled raw spot glyphs receive creation-order numeric IDs solely to satisfy the original full-ordinate comparator; native canonical identities are normalized by glyph content. These observers are bounded method/scheduling controls, not a full BEAMS pipeline comparison. The existing point empty-area NaN and stem nonfinite-intersection behavior remains unchanged.

Focused tests, fmt and workspace all-targets Clippy pass. The preserved 259 debug/259 release baseline at 549d409 is historical; full workspace/release checks have not been rerun for this spot stage. Full extension loop/CLI integration, parallel processing, late hooks/groups, notes, rhythm and MusicXML remain unfinished.
