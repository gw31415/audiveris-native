# Multiple-rest admission and serif query boundary

`multiple_rest_admission::assess_candidate` implements the pinned original MultipleRestsBuilder.process admission predicates. Removed candidates, hooks and small beams are excluded. Normal beam bounds must be at least the rounded four-interline minimum width. The caller supplies the original staff association and endpoint pitch measurements: no staff, tablature, and either absolute endpoint pitch above 0.2 reject. Passing candidates receive LEFT then RIGHT serif queries at bounds.x and bounds.x+width-1 with half-even-rounded beam height minus mid-line thickness. No beam, group or registry is mutated. This is a completed admission subset, not completed rest recognition.

73 independent original-JAR controls invoke uninterrupted MultipleRestsBuilder.process on actual staff/raster data and supplied beam medians, with 26 reaching its projector. Sheet scale and the actual staff's declared specific interline are varied explicitly over 15, 16 and 17; actual original endpoint pitch measurements are retained. Direct original getSerifPeaks and processMultiRestSide calls capture query-derived peak lists. All peak lists were empty and no rest conversion occurred in these controls. This proves admission and query setup, not positive raster serif detection. Last LEFT/first RIGHT peak selection is justified by pinned getSerifPeaks bytecode; a native nonempty order test verifies the implementation without claiming an original nonempty control.

Four focused tests across admission and group controls pass, along with fmt and all-targets Clippy. The initial oracle attempt failed because its sheet scale did not match staff specificInterline; this was corrected explicitly in the original controls. Clippy's initial collapsible-if failure was fixed and checked again. Prior provenance and the full 275 debug/release validation at groups source 6eeebead are retained. Full regression at this new tree is UNVERIFIED and deferred to a meaningful batch boundary.

Staff association/pitch computation in the native rests flow, raster serif peak detection, serif filament/glyph construction, MultipleRestInter/VerticalSerifInter registration, beam removal and group cleanup, epilog, CLI wiring and full OMR remain unfinished. No thirteen-image rest boundary or positive rest-conversion acceptance is claimed.
