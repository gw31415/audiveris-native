# Seed-stage full regression contract

Full debug and release runs after the clipped neighbor-chain seed adapter exposed stale test contracts: a previously supported straight clip was still treated as malformed, and three independent stem tests still expected eleven fixtures after the twelfth raster was added. All first-run results are retained in a separate external failure checkpoint.

The malformed case now supplies reversed horizontal ends; a positive control checks the supported straight clip and its half-open edges. The scaler, checker and stick-factory tests now include all twelve original raster fixtures. The added checker pixel PNG is decoded from the original observer's NO_STAFF mask, verified against its independent SHA256, and its slope/result provenance is appended without replacing existing records. All 356 original check contexts are compared, including four new positive seeds.

Runtime implementation is unchanged by this contract correction. Full profile results apply only to the exact source pin and logs recorded in the external validation checkpoint. No test is ignored or filtered from either full run. Beam-area preparation remains explicitly unsupported for the native horizontal raster; complete OMR and positive real-score rest recognition remain unfinished.
