# Bounded native stem extension

`SystemCandidates::extend_to_stem` ports the original private `BeamsBuilder.extendToStem` at Audiveris `9e1e55cd2746037d059345881c53e6a6754bffbd`. `side_through_stem` composes the existing side-beam/LEFT-merge prefix with this real branch. Accepted merges skip stem processing; accepted stems append a replacement and remove the old beam through the verified point boundary; rejected stems return `NeedSpot` and stop. No spot/parallel rejection stub is substituted, and the whole extension loop/CLI is not wired yet.

Selection starts from the owning system's insertion-ordered free-glyph identities, filters the global registry's VERTICAL_SEED group, intersects the original side-area with glyph bounds, then stably sorts by left abscissa. LEFT selects the last match; RIGHT selects the first. Equal x retains owner order. Only the selected seed is tried, with no fallback. Foreign-owner rows reject before mutation. Default reach is one interline, capped by the previous side-gap decision; the ordinate margin is Math.rint(0.8 * interline).

The native fitted line reproduces original Glyph.computeLine/BasicLine.toDouble and getStartPoint/StopPoint(VERTICAL), not the separate pixel-center line. Existing glyph_geometry retains its previous center-line result through a shared private fit helper. LineUtil determinant arithmetic supplies the beam intersection. Existing finite geometry/resource limits apply; single-pixel fitted lines are explicitly unsupported. Two controlled horizontal/parallel glyphs produce original Infinity/NaN intersection coordinates and reject. Native reports retain those typed values; the original JSON stores explicit strings, never numeric zero. The earlier empty-mask NaN acceptance in extendToPoint is unchanged.

126 independently generated controls invoke the unmodified original private stem method on real Book/Sheet/Grid/SIG. 58 accept. They cover ownership, group filtering, stable ties, both sides, zero/one and capped reach, strict area boundaries, original glyph line endpoints, slants, no-fallback rejection, nonfinite intersections, grade and register/append/remove lifecycle. Two controls additionally invoke original getSideBeam and LEFT extendToBeam to validate the derived 2/6-pixel side-gap caps before the stem invocation. Native one-side composition is exercised on those two and forty default-reach controls; original successful merge-prefix controls prove the early branch skips stem processing.

33 focused tests, fmt, and workspace all-targets Clippy pass. The full 259 debug/259 release baseline at 549d409 is preserved as historical evidence; full workspace/release checks have not been rerun for this new implementation stage. Full BEAMS, hooks/groups, notes, rhythm, and MusicXML remain unfinished.
