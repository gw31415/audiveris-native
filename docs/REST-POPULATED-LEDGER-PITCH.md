# Native supplied straight-ledger pitch mapping

Original Staff.pitchPositionOf reads the five staff lines at the endpoint x. Within the staff it uses the measured top/bottom span. Outside, it walks consecutive signed ledgerLineMap keys starting at -1 or +1, interpolates between the previous boundary and the first ledger beyond the ordinate, and adds two pitch steps for every passed ledger. On the first absent key it falls back from the last visited line using specificInterline; higher keys beyond a gap are ignored. This is not a nearest-line approximation.

Mapping::from_grid now accepts staff.ledger_lines entries {index,points:[[x0,y0],[x1,y1]]}. Nonzero signed indices and unique keys are required. The native Curve interpolation/extrapolation represents an original straight GeoPath. Curved ledger paths, malformed maps, crossing/reversed ledger order at the queried x and non-five-line/unsupported staff areas remain explicit errors. pitch_at follows the original consecutive-key walk; beam endpoint pitch uses this same method.

The independent PopulatedLedgerPitchControlProbe calls the unmodified pinned Audiveris Staff.pitchPositionOf with supplied sloped staff curves and straight GeoPath ledger maps. Its 220 cases cover consecutive/gapped keys on both sides, missing first keys, one-sided maps, exact boundary ordinates, staff-span interpolation, fallback beyond the final ledger and x outside the supplied path. Native outputs were not used to generate expectations. Existing 21 empty-ledger controls and eleven complete conversion controls remain unchanged.

Native GRID is pre-LEDGERS and currently emits empty ledger_lines. This stage adds correct supplied populated-map consumption, not native ledger discovery. The current raster pipeline still rejects multi-staff/multi-system rest mapping. Original SystemInfo.getStaffAtOrAbove first calls StaffManager.getClosestStaff: this restricts candidates through actual Staff.getArea containment, resolves overlap by Staff.distanceTo with encounter-order ties, and chooses the preceding system staff if the point lies above the closest staff's first line. Correct native area serialization/containment and per-system lag ownership are still missing; nearest vertical staff heuristics are not substituted.
