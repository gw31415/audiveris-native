# `scoretool.py summary` の記法

```
P2 m3 S2 key=-4 time=3/4 staves=2 clef1=G2 clef2=F4
  st1 v1: <F4+Bb4+F5>:8 Eb5!b~:q. R:8
  st2 v5: Db3:8.caes C3:8 g:D3:16 C3:8(
  dir dyn:f (staff2) [below]
  bar right light-heavy repeat-backward
```

| 記法 | 意味 |
|---|---|
| `P2 m3 S2` | パート P2 の小節番号 3、段 S2（`crops` の `S02*.png`） |
| `key=-4` | 調号（fifths: 正=♯の数、負=♭の数） |
| `time=3/4(common)` | 拍子（括弧は記号 common / cut） |
| `clef1=G2`, `F4`, `C3`, `G2-1` | 五線番号ごとの音部記号（記号・線、末尾はオクターブ変化） |
| `implicit` | 番号に数えない小節（弱起など） |
| `st1 v1:` | 五線 1・声部 1 の音の列 |
| `Eb5` | 音高（実音の綴り。`#` `b` `x` `bb`） |
| `!n` `!#` `!b` | 臨時記号が実際に表示される（ナチュラル等） |
| `~` | その音からタイが始まる |
| `<A+B>` | 和音 |
| `:q` `:8` `:16.` | 音価: `w` 全・`h` 2分・`q` 4分・`8` 8分・`16`… 付点は `.` |
| `[3:2]` `{` `}` | 連符（実際 3 音を通常 2 音分）、連符括弧の開始・終了 |
| `R` `R(measure)` | 休符、全小節休符 |
| `g:` | 装飾音符 |
| `(` `)` | スラーの開始・終了 |
| `.stacc` `.acc` `.ten` `.marc` `.ferm` `.trill-mark` `.arp` `.caes` … | アーティキュレーション・装飾 |
| `"Trau-"` | 歌詞（`-` は音節の続き。`"2:..."` は 2 番） |
| `dir` | 強弱 `dyn:`、文字 `words:`、ヘアピン `wedge:`、オッターヴァ `8va:` など |
| `bar` | 小節線の種類・反復・ボルタ |
