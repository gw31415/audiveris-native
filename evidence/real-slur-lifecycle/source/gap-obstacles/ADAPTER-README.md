## Required behavior

* `grouped_extension_boxes` receives every unfiltered native single/pair candidate. Each left component group starts with its actual endpoint's 1×1 rectangle and adds every right endpoint without an extra pixel. Grouping happens before model, gap or obstacle rejection. Endpoint membership is checked against actual retained vertical glyph runs. This preserves the source all-reachable-endpoints envelope for the current native alternatives; it does not claim original Skeleton reachability.
* For each candidate, route its actual left endpoint through retained System areas. Borrow live Graph vertices from each routed System, selecting source Head/Beam/TEXT/LYRICS families and `frozen || best_grade >= 0.4`. `Skeleton.CurvesCleaner` inherits `PageCleaner.canHide`; the Head 0.6 threshold belongs to `SymbolsFilter` and was incorrect here.
* Preserve bounds-versus-extension and optional actual Area-versus-extension prefilters, then exact endpoint segment-versus-bounds and full-endpoint two-pixel strip-versus-Area checks. The source rejects a crossing candidate; it does not abort every candidate. A genuine unknown owner/Area still returns an explicit error.
* Ordinary automatic Heads have the source null-Area branch. Ordinary Beam/BeamHook Areas use their retained full-precision median and height, through `AreaUtil.horizontalParallelogram` geometry. Manual/explicit-Area or intersecting TEXT/LYRICS owners remain pending. No coordinates, IDs or masks from an original fixture enter production selection.

The Graph and actual music owners are read only during this filter. Its false result discards a candidate before raw support, Slur registration or cleanup. The existing staged publication and rollback remain intact. Because correcting 0.6→0.4 can enlarge the obstacle set, both required images must be rerun after integration; the earlier AnLaura pass alone is insufficient.
